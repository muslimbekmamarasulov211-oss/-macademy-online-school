# Background music

`tinch.mp3`, `ilhom.mp3`, `energiya.mp3` are **original loops generated by this project's own
synthesizer** (`scripts/music/generate.ts`, `npm run music:generate`). They contain no samples
or third-party music, so they are free to use in your videos.

To use your own music, put an `.mp3` here (a–z, 0–9, `-` in the file name). It appears in the
generator's music list. Only use music you have the rights to.
